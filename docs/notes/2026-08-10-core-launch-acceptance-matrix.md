Companion to `2026-08-10-market-core-backend-readiness.md`.

**175 rows.** A row is `existing` only when a named test file actually covers it;
`blocked` means a verified blocker (B1..B7) prevents the test being written at all, and the
evidence column names the blocker.

| missing | 57 |
| blocked | 22 |

Money scenarios carry concrete aurar figures and the expected ISK line, because the rounding
boundary is where a statement stops agreeing with itself.
