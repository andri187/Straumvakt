# DECISIONS

One line per decision. Newest first.

This replaces the ADR habit for the market phase. The ADR-per-decision
ceremony produced 51 documents that exceeded what anyone could hold, so each
new question got answered fresh instead of looked up — which is how three
billing generations happened. See [FOCUS.md](./FOCUS.md) rule 8.

**How to add an entry:** date, one sentence, and the consequence if it is not
obvious. No template, no status field, no supersession chain.

**When to write an ADR instead:** only when a decision is genuinely
load-bearing *and* irreversible — a schema shape that will carry money, or a
boundary that other people will build against. Expect that to be rare. If you
are reaching for an ADR to think out loud, write the line here instead.

| 2026-08-28 | **Provenance is temporal-by-default, not a parallel audit system.** The model already closes rows rather than deleting them — placements, memberships, clauses — arrived at three separate times for three separate reasons. **Where a table is dated, the history IS the audit**, so the rule is: anything deciding money or access is dated and closed, never mutated, and a trigger-written audit covers only the mutable remainder (an org's address, a user's name). **Add transaction time alongside valid time** on those tables, so a backdated correction is visible as a correction rather than as history that always looked that way. **Humans get read-only credentials to production; only the application writes** — removing the ability rather than detecting the act, and it costs nothing. Rejected: full event sourcing (ceremony rather than safety at this size, and the benefit is already had on the tables that need it) and further internal tamper-proofing (**nothing inside a database defeats its owner**). **The customer-facing trust artifact is the invoice provenance block — what was measured, what a person asserted, which rate version — not the audit trail.** A signed document hash only if a customer asks. Consequence: the acceptance test "no row created by hand" is guaranteed by access control and the temporal model, and merely *reported* by a provenance query. |
